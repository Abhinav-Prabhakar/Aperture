The layers

Three layers. One system.

Start with an element. Compose an instrument. Ship a workbench.

01

Elements

Accessible primitives with the Aperture design language. Buttons, fields, tables, dialogs, navigation — the parts you should never rebuild.

56 vendored from coss/ui

02

Instruments

Research-native components that solve one real problem well. Measurement tables, exclusion ledgers, result blocks, spectra, dose–response curves.

26 built, including 8 research records

03

Workbenches

Complete screens with navigation, canvas, inspector, status bar, empty states, and the details that take another month.

5 in the first release

Principles

Designed like an instrument.

Quiet surfaces, precise edges, and defaults that respect the data.

01

Chrome is achromatic.

Color belongs to the data. The interface stays quiet so the measurement, image, or map can speak.

02

Dense by default.

Researchers read tables for a living. Density is a feature when it is structured, aligned, and predictable.

03

Show the state.

Units, uncertainty, missing values, provenance, and run status are never hidden. Missing data is not zero.

04

Accessible is not optional.

Keyboard-first, screen-reader-aware, colorblind-safe, reduced-motion-safe, RTL-ready, legible at 200% zoom.
