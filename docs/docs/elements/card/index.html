Card

A bordered surface for one coherent object: a sample, a run, a dataset, a settings group. A card is not a layout container.

Anatomy

PartJob
CardHeaderTitle, description, and an optional action in column two.
CardPanelThe body. The only part that scrolls if the card is fixed.
CardFooterStatus and actions. Right-align primary actions.
CardActionA single icon or menu; it spans both header rows.

Rules

  • One object per card. If it needs tabs, it is a page or a panel.
  • Put units in the label or the value, never in a tooltip.
  • Use a table for comparison, a card for a single record.
  • Do not nest cards. Use Frame or CardFrame for grouped panels.
  • The footer is for state and actions, not for more data.
