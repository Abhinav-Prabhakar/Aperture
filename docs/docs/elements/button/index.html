ElementStable in coss/ui

Button

The primary action control. One default action per view; everything else is outline, ghost, or a menu item.

Variants

Sizes

Heights are one step larger on touch: 28/24, 32/28, 36/32, 40/36, 44/40 (mobile/desktop).

Loading and disabled

Loading preserves the button width, hides the label from sighted users, and sets aria-disabled. It is not a substitute for a progress indicator when the operation is long.

Composition

Instruments

Anatomy

PropertyValue

Icon18/16 px, 80% opacity, 2 px optical pull
Motionshadow only; no scale or translate

Rules

  • Use one default button per view. If everything is primary, nothing is.
  • Destructive actions name the object: “Delete sample”, not “Delete”.
  • Icon-only buttons require an accessible name.
  • Do not put a button inside a button or a link inside a button.
  • For navigation, render a link; do not attach an onClick to a button.
