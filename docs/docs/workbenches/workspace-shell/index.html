Workspace Shell

The frame around every other screen. Navigation, breadcrumbs, a command palette, an inspector, a status bar, and mobile drawers — without a sidebar that becomes a second product.

Open the workspaceThe workbench previews on this site run inside it.

What is inside

  • A quiet sidebar. Grouped navigation with icons, optional counts, and an active state. On small screens it becomes a left sheet; the page keeps its scroll position.
  • A command palette. ⌘K or Ctrl K searches every page and host action. Arrow keys, Enter, and Escape work without a mouse.
  • Breadcrumbs with a place. Workspace, section group, and page. The active nav item is derived by the host, so the shell does not guess from a URL it does not own.
  • An inspector slot. A right panel on desktop, a right sheet below that. The host supplies the contents; the shell supplies the frame, close control, and focus return.
  • A status bar with facts. Connection state, the fixed asOf instant in UTC, a keyboard hint, and a version. No fake live clock.
  • Print without chrome. The top bar, sidebar, inspector, and status bar disappear; the workbench's own print header remains.

Layout states

  • Ready and offline. Offline replaces the connection line in the status bar and leaves the cached content in place.
  • Navigation closed, open, and dismissed. Desktop keeps the sidebar; mobile opens a labeled sheet and returns focus to the trigger.
  • Inspector open and collapsed. The toggle reports its state, and the panel has its own accessible name.
  • Command palette idle, searching, and empty. An unmatched query says so instead of showing a blank list.

Data contract

  1. Navigation in. Pass groups of items with an href, a stable id, and an optional icon, badge, or description. The shell renders links; your router decides what they mean.
  2. Commands in. A command can be a route, an external URL, or a run() callback. Every navigation item is added to the palette automatically.
  3. Navigation out. onNavigate(href, event) is called after the default is prevented. Without it, links navigate normally and commands use window.location.
  4. Actions out. onCommand(command) fires for every selection, before the command runs. Use it for analytics, permission checks, or persistence.

Install

Composition

Built from Breadcrumb, Command, Sheet, Avatar, Kbd, and Button. The host supplies pages, user, actions, and inspector content. No private runtime and no hidden provider.

Accessibility

  • A skip link targets the scrollable main region.
  • The sidebar is a labeled nav; the active item uses aria-current.
  • Dialogs have accessible names, close buttons, and focus return. The command input is a labeled combobox.
  • Inspector and navigation toggles report aria-expanded and control a named region.
  • Every icon-only control has a label; the status line is announced with role="status".
  • Logical properties and mirrored chevrons keep RTL layouts honest.
