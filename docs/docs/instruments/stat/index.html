Stat

One number that matters, with its unit and context. Use a grid for a run summary; use a table when the values need to be compared row by row.

Versus run 11

Rules

  • Put the unit in the value or beside it. A stat without a unit is a number, not a measurement.
  • Use the hint for sample size, comparison, or method — not for a second value.
  • Up is not good and down is not bad. The arrow shows direction only; color and valence are the author’s decision.
  • More than about eight stats in a grid is a table. Switch before the reader has to hunt.
  • Pass a ScientificNumber when precision matters; pass a string when the value is already formatted.
