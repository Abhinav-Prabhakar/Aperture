Scientific Number

A measured value is not just a number. It carries precision, a unit, and often an uncertainty. This component keeps all three together — and keeps the full value within reach.

Display

Default3.42 × 10⁻⁶m³/kg
With uncertainty(3.42 ± 0.18) × 10⁻⁶m³/kg
Fixed precision12.40mm
Copyable3.00 × 10⁸m/s

Formatting rules

SituationDisplay
0.00000342 with 3 s.f.3.42 × 10⁻⁶
12.4 ± 0.212.40 ± 0.20 (aligned)
−0.01234−0.0123 (true minus sign)
12 with 3 s.f.12.0 (trailing zero kept)
1234 with 3 s.f.1230
No reading— (not 0)

Rules

  • Significant figures are a property of the measurement. Do not round them away for visual consistency.
  • Put the unit after the value, in muted text. Never bury it in a tooltip.
  • Use a true minus sign (−) and a multiplication sign (×), not a hyphen and an x.
  • copyable copies the unrounded value, its uncertainty, and the unit — enough to reproduce the analysis.
  • For tables, right-align values and units; for prose, let the number flow inline.
