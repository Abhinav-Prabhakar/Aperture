A synthetic ten-point viability series for a fictional compound, AP-17, in HeLa cells. Three replicates per dose, one missed read, and a fitted IC50 of 0.405 µM. Switch between log and linear, hide the replicate points, hover the chart or focus it and use the arrow keys, open the data table, or export the CSV.

What it checks

  • Replicates stay visible. Each dose shows the individual reads, the mean, and a ±1 sample SD bar. The table reports the reads, mean, SD, and n per dose. A dose with one read has no SD.
  • A missed read is a gap. null is never filled with zero, the mean, or an interpolated value. It appears as — in the table and as an empty cell in the CSV.
  • The fit reports its shape. The instrument fits a four-parameter logistic curve to the dose means and reports the low-dose plateau, high-dose plateau, Hill slope, half-maximal concentration, R², and the number of points used.
  • The direction changes the name. A falling curve is inhibition and reports an IC50. A rising curve is stimulation and reports an EC50. The Hill slope stays positive; the plateaus carry the orientation.
  • The band is a fit band. The shaded 95% band is a confidence band for the fitted mean response, not a prediction interval for a new well. It is asymmetric in dose because the fit is done in log space.
  • The export is the data. CSV columns carry every raw read, the mean, SD, count, and the fitted response — not the plotted coordinates. Labels containing commas or quotes are escaped correctly.

How the fit works

The model is a four-parameter logistic on the mean response at each positive dose:

  • The fit needs at least four positive doses with a mean. A vehicle or other non-positive dose is kept in the table but excluded from the fit and hidden on the log axis.
  • Starting plateaus are the low-dose and high-dose means; the starting half-max comes from the first crossing of the midpoint. A Levenberg–Marquardt least-squares loop refines the four parameters.
  • The fit must reach R² 0.50 to be reported. Below 0.90 the instrument says “Check fit” and asks you to inspect the points before using the half-max.
  • The 95% interval for the half-max is computed on the log10 scale from the covariance of the four parameters, then exponentiated. The band uses the delta method at each plotted dose.
  • The fit is unweighted and uses one mean per dose. It does not model plate effects, drift, or unequal variance between doses.

A tight interval does not make a curve correct. Check the design, background correction, normalization, and the fit residuals before reporting a half-max — especially when the top or bottom plateau is not reached.

Data contract

  1. Data in. data is null or an object with an id, a name, replicates, and points. Optional fields add compound, cell line, duration, instrument, units, and source. Null or all-missing data renders the empty state.
  2. One array per replicate. Each dose carries values in the same order as replicates. A null or non-finite reading is a missed read. Points are sorted by dose; non-finite doses are ignored.
  3. Units are explicit. doseUnit defaults to µM; responseLabel defaults to Viability and responseUnit to %. They appear on the axes, in the statistics, and in the CSV header.
  4. Fit thresholds are adjustable. Pass fitOptions={{ minPoints: 6, minRSquared: 0.9 }} to tighten or relax the analysis. Pass showFit={false} to hide the fit and show only the reads.
  5. Display controls are local. defaultScale and defaultShowReplicates set the initial view. The scale, replicate toggle, and table state are owned by the component; the data is never mutated.
  6. Export is observable. onExport(csv) fires before the browser download, so a host can log, validate, or replace the file. The component does not upload anything.
  7. Pure helpers are exported. summarizeDoseResponse, fitDoseResponse, predictDoseResponse, doseResponseBand, and doseResponseCsv. Use them in a notebook, a validation script, or your own pipeline.

Accessibility

  • The chart exposes a slider role with the current dose, mean, SD, count, and fitted response as its value text. Arrow keys, Home, and End work without a pointer.
  • On a log axis the cursor skips non-positive doses, so every focused value is visible on the chart. The table still contains every row.
  • A screen-reader summary states the replicate count, dose range, half-max and interval, fit direction and R², and missed reads.
  • The data table is a real table with column headers and an explicit — for missing values. It is toggleable on screen and shown in print.
  • Status is never color alone: the fit label says “Good fit”, “Check fit”, “No fit”, or “Hidden”, and the missing-read count is text.
  • Layout uses logical properties and container queries. At 320 px the analysis moves below the chart without a page-level horizontal scroll.
  • There are no entrance animations or counting numbers. Reduced-motion users see the same chart immediately.

Preview status

The rendering, helpers, keyboard path, and export are complete and tested. The defaults still need a domain-advisor review: blank correction, normalization to vehicle, whether to fit means or all replicate points, weighting, shared or fixed Hill slopes, the R² threshold, and the confidence-interval convention. Treat this instrument as usable, not final. The Growth Curve and Sequence Viewer carry the same preview status.
