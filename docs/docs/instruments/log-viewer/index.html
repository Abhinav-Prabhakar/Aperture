Log Viewer

What happened, when, and where. A run log has to stay readable at 2 a.m., with a thousand lines, on a laptop at the bench.

Anatomy

PartBehavior
TimeShort display time; the machine-readable moment goes in dateTime.
LevelDebug, info, warn, or error. Always a word, never only a color.
SourceThe producer: reader, pump, analysis, export. Makes multi-process logs usable.
FollowKeeps the newest line in view. Turn it off to read history without being pulled down.
FilterHides levels; it does not delete them. The count shows what is hidden.

Rules

  • Put the interesting fact first. “Well D7 saturated” beats “Warning while reading”.
  • A warning is a result with a caveat; an error is a failure. Do not use one for the other.
  • Keep secrets out. Logs are copied into tickets, notebooks, and papers; redact at the source.
  • Use announce only for a single monitored line, not a streaming log.
  • This component presents entries. It does not rotate, store, or transmit them.
