Data Table

Rows are observations; columns are quantities. The table keeps units, precision, missing values, and quality flags in their proper places.

Sort by a header, or select a row. Missing concentration is shown as — and sorts last, in either direction.

Rules

  • One unit per column, shown once in the header. If the unit changes by row, the unit belongs in the cell, not the header.
  • Right-align numbers and use tabular numerals. Do not center a column of measurements.
  • Missing is not zero. Render — with an explanation, and sort it last.
  • Sorting is stable. Equal values keep their original order, so a second sort does not scramble the first.
  • Selection is by stable row id, not index. Give every row a checkbox name a person can read.
  • This table sorts and renders in memory. For thousands of rows, add virtualization or server-side paging rather than shipping them all.
