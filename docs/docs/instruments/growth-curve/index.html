A synthetic E. coli curve with a lag, exponential phase, and stationary phase across three wells. Two reads are missing. Switch between log and linear, hide the replicate traces, hover the chart or focus it and use the arrow keys, open the data table, or export the CSV.

What it checks

  • Replicates stay visible. The mean is the solid line, the band is ±1 sample standard deviation, and each well keeps its own trace. The table reports the mean, SD, and n at every time point. A single read has no SD and no band.
  • A missed read is a gap. null breaks the trace and appears as — in the table and an empty cell in the CSV. It is never filled with zero or interpolated silently.
  • Log phase is a fit, not a label. The instrument fits ln(mean) against time over a candidate window and reports the doubling time, growth rate, R², and the number of points used. The shaded window is a starting point for review, not a conclusion.
  • The scale changes the view, not the data. Log is the default because exponential growth is a straight line there. Linear is one click away. Non-positive reads cannot be drawn on a log axis; they are counted, hidden with a warning, and kept in the table.
  • Every point is inspectable. The chart behaves as a slider over time points. Arrow keys, Home, and End move the cursor; the readout and the accessible value report the time, mean ± SD, and n.
  • The export is the data. CSV columns carry the raw replicate readings, mean, SD, and count — not the plotted coordinates. Labels containing commas or quotes are escaped correctly.

How log phase is detected

The fit is ordinary least squares on ln(mean OD) against time:

  • Candidate windows need at least four consecutive positive means and an R² of at least 0.97.
  • A window may not begin or end in a phase whose local growth rate is less than half the fitted rate. This keeps a flat lag point from widening the window just because it raises R².
  • Among the windows close to the best R², the longest one wins. The default tolerance is 0.003.
  • Override the heuristic with an explicit window when you know the experiment: logPhase={{ start: 2, end: 7 }}. Pass showLogPhase={false} to hide the analysis entirely.

A high R² does not make a window biologically correct. Check the boundaries against the design of the experiment before reporting a doubling time — especially when the lag and exponential phases are not sharply separated.

Data contract

  1. Data in. data is null or an object with an id, a name, replicates, and timepoints. Optional fields add strain, medium, temperature, instrument, units, and source. Null or all-missing data renders the empty state.
  2. One array per replicate. Each time point carries values in the same order as replicates. A null or non-finite reading is a missed read. Time points are sorted by time; non-finite times are ignored.
  3. Units are explicit. timeUnit defaults to h; valueLabel defaults to OD600. Both appear on the axes, in the statistics, and in the CSV header.
  4. Display controls are local. defaultScale and defaultShowReplicates set the initial view. The scale, replicate toggle, and table state are owned by the component; the data is never mutated.
  5. Export is observable. onExport(csv) fires before the browser download, so a host can log, validate, or replace the file. The component does not upload anything.
  6. Pure helpers are exported. summarizeGrowthCurve, fitLogPhase, detectLogPhase, and growthCurveCsv. Use them in a notebook, a validation script, or your own pipeline.

Accessibility

  • The chart exposes a slider role with the current time, mean, SD, and count as its value text. Arrow keys, Home, and End work without a pointer.
  • A screen-reader summary states the replicate count, time range, fitted window, doubling time, R², and missed reads.
  • The data table is a real table with column headers and an explicit — for missing values. It is toggleable on screen and shown in print.
  • Status is never color alone: the missing-read count and the non-positive warning are text, and the log-phase badge says “Detected” or “Not detected.”
  • Layout uses logical properties and container queries. At 320 px the analysis moves below the chart without a page-level horizontal scroll.
  • There are no entrance animations or counting numbers. Reduced-motion users see the same chart immediately.

Preview status

The rendering, helpers, keyboard path, and export are complete and tested. The defaults still need a domain-advisor review: blank correction, the R² threshold, the lag-phase boundary, and the doubling-time convention. Treat this instrument as usable, not final. The Sequence Viewer carries the same preview status.
