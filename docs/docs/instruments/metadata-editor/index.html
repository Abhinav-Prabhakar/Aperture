Metadata Editor

The result is only half the record. Metadata says which instrument, which protocol, and who ran it — the part that makes the result reproducible.

Live

Run metadata

Stored with every export and shown beside the results.

  • Protocol
  • Notes

Rules

  • A key is a schema promise. Keep required keys fixed; let people add custom keys instead of renaming the ones your analysis reads.
  • Values stay strings. Preserve leading zeros in IDs and use ISO 8601 for dates; do not let a display format become the stored value.
  • Empty is not unknown. Use an explicit “Not recorded” value when the field applies but the answer is missing.
  • The editor does not validate or save. Validate on submit and keep the last saved copy so a failed save cannot destroy metadata.
  • Removing a custom field is not deletion of the record. Confirm before discarding provenance.
