InstrumentMeasurementReady

Quantity Input

A value, its unit, and its uncertainty entered together. Changing the unit converts the number instead of relabeling it.

Live

Reported as mean ± standard deviation.

±

Try mg/L → µg/mL. The value and its uncertainty convert; the number is never silently relabeled.

Anatomy

PartBehavior
Numeric fieldAccepts decimals and exponent notation; keeps intermediate text while typing.
Unit menuConverts the value and uncertainty on change. Incompatible units are rejected.
Uncertainty fieldOptional. Absolute, in the same unit. Negative values are rejected.
HintNames the uncertainty kind: SD, SEM, 95% CI, or range.
ErrorEmpty, non-numeric, out of range, or external. Never silently clamps.

Rules

  • Missing is not zero. Empty stays empty and is reported as null.
  • Name the uncertainty kind. “± 0.2” alone is ambiguous.
  • Precision is a display choice. Keep the underlying value at full precision.
  • Do not clamp silently. If a value is out of range, show the error and let the researcher decide.
  • A unit menu is a promise: every option must be dimensionally compatible.
