Status Badge

A state is a fact, not a decoration. The dot carries color, the label carries meaning, and the description explains what happened.

Live

AcquiringPlate reader · run 12
IdleRunningCompleteNeeds attentionFailedOffline

States

StatusDefault labelMeaning
idleIdleQueued or waiting. Not an error.
runningRunningWork is in progress and the value may still change.
successCompleteFinished as expected. Use past tense in the label.
warningNeeds attentionFinished, but outside the expected range.
errorFailedStopped without a usable result.
offlineOfflineThe instrument cannot be reached.

Rules

  • Never use color alone. Every status has a visible label; a dot alone is only acceptable when the label is repeated nearby.
  • Use the tense of the event: “Running” while it happens, “Complete” or “Failed” once it ends.
  • A warning is not an error. Say what needs attention, not just that something does.
  • Announce changes only when the change matters. A page full of role="status" regions is noise.
  • The description is for cause and next step. Do not repeat the label in it.
