InstrumentMeasurementReady

Uncertainty Input

A number without an error is not a measurement. This input keeps the value and its uncertainty together, and shows the exact form that will be saved.

Symmetric

µg/mL
±

Standard deviation of three technical replicates.

Reported as 12.5 ± 0.3 µg/mL

The reported form follows the uncertainty, not the typed text: 12.47 with an error of 0.32 is displayed as 12.5 ± 0.3. Pass precision only when the protocol fixes the number of decimal places.

Asymmetric

h
−
+

95% confidence interval from the fit. Errors are not symmetric.

Reported as 14.2 +1.8 / −1.5 h

Pass { lower: 1.5, upper: 1.8 } for half-widths, not interval endpoints. Both must be non-negative, and the pair is entered or cleared together.

Rules

  • Store value and uncertainty as numbers in the same unit. Formatting is a view; it must never be parsed back into the saved record.
  • One or two significant digits on the uncertainty is the convention here. Do not report more precision in the value than the error supports.
  • An asymmetric error is a pair of half-widths. If your source reports interval endpoints, convert once at the boundary and test it.
  • Zero uncertainty and unknown uncertainty are different states. Zero means exact — an integer count, a defined constant — and is displayed without a ± term. Unknown is null.
  • The preview is the contract. If the reported form would lose a trailing zero or change the order of magnitude, fix the formatting before saving.
  • Validation appears on blur, not on every keystroke. Typing “-” is not an error until the field is left.
