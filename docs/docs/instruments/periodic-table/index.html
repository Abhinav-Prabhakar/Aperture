All 118 elements, with iron selected by default. Color marks the block (s, p, d, f), not the chemical family. Hover or focus a cell and use the arrow keys to move through the grid; search by name, symbol, or atomic number; switch the trend between electronegativity, atomic radius, and first ionization energy; open the full table or export the CSV.

What it checks

  • The layout is conventional. Eighteen columns, seven main periods, and two f-block strips below the table. Lanthanum through lutetium and actinium through lawrencium sit in the strips at columns 3–17. Group 3 in periods 6 and 7 is left as a gap rather than asserting a disputed placement.
  • One tab stop, many cells. The grid uses a roving tab index, so Tab enters the selected element and the arrow keys move through occupied neighbors. Home and End jump to the ends of the current row. Focus follows selection, and the detail panel updates with it.
  • Search is a shortcut, not a filter. Names, symbols, atomic numbers, categories, and blocks match. The matching elements appear in a result strip; Enter selects the first match and moves focus to its cell. The grid stays whole so the shape of the table is never lost.
  • The detail panel is complete. Atomic number, symbol, name, category, block, period, group or series, atomic weight, electron configuration, Pauling electronegativity, radius, first ionization energy, electron affinity, oxidation states, standard state, melting and boiling points in kelvin and Celsius, density with its unit, and year discovered.
  • A missing standard weight is marked. Elements without an IUPAC standard atomic weight show their mass with an asterisk and a note. The mass is a representative isotope mass, not a bracketed mass number presented as an atomic weight.
  • Trends are per period or series. The sparkline reads the selected element's row in the table. It is a shape check, not a regression; every value is also visible in the detail panel and the full table.
  • The export is the data. The CSV carries all 118 elements with atomic number, symbol, name, category, block, period, group, mass, standard-weight flag, electronegativity, radius, ionization energy, electron affinity, oxidation states, standard state, melting and boiling points, density, density unit, and discovery year.

Reading the table

  • Block is the only color. The four tints mark s-, p-, d-, and f-block. Chemical family is written in the detail panel and in the table; it is not inferred from hue.
  • Mass units are unified. Atomic weights are in unified atomic mass units (u). Density is g/cm³ for condensed phases and g/L for gases; the unit is always shown.
  • Temperatures are dual. Melting and boiling points are stored in kelvin and displayed in kelvin with a rounded Celsius value. A missing point is an explicit —, not a zero.
  • Discovery is text. Years are strings because some entries are “Ancient” or otherwise not a single year. The table does not sort discovery dates numerically.

Data contract

  1. Bundled data. The default dataset is all 118 elements in periodic-table-data. Pass elements to replace it with a subset or your own reviewed values.
  2. Required per element. Atomic number, symbol, name, mass, category, block, period, and group. The group is null for f-block strips. Optional numeric properties are null when unavailable.
  3. Selection is observable. onElementSelect(element) fires on click, keyboard navigation, and search selection. The component owns the selected number; the data is never mutated.
  4. Pure helpers are exported. PERIODIC_LAYOUT, findElementNeighbor, searchElements, formatAtomicMass, formatDensity, formatKelvin, and elementCsv.
  5. Export is observable. onExport(csv) fires before the browser download. The component does not upload anything.

Provenance

Values are compiled from PubChem periodic-table records through periodic-table-data 1.1.1 (MIT). Group, period, and block are derived from the conventional 18-column layout. Atomic weights and bulk properties are reference values, not a validation source. Verify against IUPAC/CIAAW and NIST before publication. The component does not include isotope abundances, decay data, or a full electron-shell diagram.

Accessibility

  • The grid is a group of real buttons with atomic number, symbol, name, category, and block in each accessible name. Selection uses aria-pressed.
  • Roving tab index keeps the grid to one tab stop. Arrow keys, Home, and End move selection and focus without wrapping across empty cells.
  • The search box has a visible label path, an Escape shortcut, and a live result count. Enter moves focus to the first match.
  • The detail panel is a heading-led definition list. The trend is an image with a full text alternative, and the full table is a real table with column headers.
  • At 320 px the grid scrolls inside its own region, with the page-level layout intact. Block tints have text labels in the legend.
  • There are no entrance animations or counting numbers. Reduced-motion users see the same table immediately.

Preview status

The layout, navigation, search, detail panel, trend, table, and export are complete and tested. The defaults still need a domain-advisor review: the La/Lu and Ac/Lr placement convention, the category labels, the atomic-weight precision, the gas-density conversion, the trend properties, and the discovery-year strings. Treat this instrument as usable, not final. The Spectrum Plot and Constants Reference carry the same preview status.
