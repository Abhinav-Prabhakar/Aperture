What “done” means

  • Registry item, docs page, and a visual test fixture.
  • Light, dark, and Contrast themes at 375, 768, and 1280 px.
  • Keyboard-only and screen-reader paths; RTL; reduced motion.
  • Logic tests with cited reference values.
  • An export path or an accessible fallback where relevant.
  • A domain advisor has reviewed the defaults and vocabulary.
  • It appears in at least one recipe.
