Constants Reference

A constant is a value, a unit, an uncertainty, a year, and a source. Keep all five together, make exactness visible, and let someone copy a number without retyping it from a PDF.

The complete CODATA 2022 listing: 355 constants, 20 featured values, and the seven defining constants of the SI. The fine-structure constant is selected to show a measured value with a one-sigma uncertainty. Search across names, symbols, values, and units; switch subsets; move through the list with the arrow keys; copy the value or the value with its uncertainty; export the visible set as CSV.

What it checks

  • The full listing is present. All 355 constants from the CODATA 2022 complete listing are bundled, not just the famous twenty. Brand-new constants in a future CODATA release arrive through the same data contract.
  • Exactness is a first-class state. The 81 exact constants carry no uncertainty and are marked “Exact” in the list and the detail panel. Measured constants show an explicit plus-or-minus value with the same unit and prefix as the value.
  • Three curated views. Featured (20 hand-picked constants), SI defining (the seven constants that define the base units), and All (355). The search applies within the active view, so “Planck” in Featured and “Planck” in All answer different questions.
  • Search is broad on purpose. Names, symbols, ids, values, and units match. Searching 299792458 finds the speed of light; searching J Hz^-1 finds the constants with that unit.
  • Copy is unambiguous. “Copy value” writes the NIST value with group separators removed and the exponent intact, for example 6.62607015e-34. “Copy ±” writes the value, uncertainty, and unit together for prose. Exact constants copy with an explicit “(exact)”.
  • Units are typeset, not retyped. NIST shorthands such as m^3 kg^-1 s^-2 render as m³ kg⁻¹ s⁻², and ohm renders as Ω. The CSV keeps the raw NIST strings.
  • Every selection is inspectable. The detail panel reports the symbol, unit, uncertainty, source year, and identifier. The list uses a roving tab index; Arrow Up and Arrow Down move selection and focus, Home and End jump to the ends.
  • The export is the visible set. CSV columns carry id, name, symbol, value, uncertainty, unit, exact flag, featured flag, and SI-defining flag. Filtering to the seven SI constants and exporting produces a seven-row file.

Reading the values

  • NIST notation is preserved. Values are stored exactly as the complete listing prints them, including space-grouped digits and the trailing e exponent. The screen rewrites the exponent as a power of ten; the CSV does not.
  • Uncertainty is absolute. The reported uncertainty is the standard uncertainty in the same unit as the value, not a relative percentage. Some values repeat the exponent in the uncertainty, as NIST publishes them; the component does not combine them into a single decimal.
  • Dimensionless means dimensionless. An empty NIST unit renders as “dimensionless,” not as a dash and not as an invented unit.
  • Truncation is disclosed. Some exact constants are abbreviated by NIST with an ellipsis, for example 1.054 571 817... e-34. The component keeps the ellipsis and shows a warning. It does not invent the missing digits.
  • The year is part of the value. These are CODATA 2022 recommended values. A future adjustment is a new dataset, not an in-place edit of the bundled one.

Data contract

  1. Data in. constants is an array of objects with an id, name, value, uncertainty, unit, exact flag, featured flag, and SI-defining flag. A symbol is optional. A missing or empty array renders the empty state.
  2. Initial view. defaultFilter selects featured, SI defining, or all. If defaultConstantId names a constant outside that filter, the component opens All so the requested constant is visible.
  3. Selection is observable. onConstantSelect(constant) fires on click and keyboard navigation. The component owns the selection and the filter; the data is never mutated.
  4. Pure helpers are exported. formatConstantValue, formatConstantUnit, constantPlainValue, formatConstantUncertainty, filterConstants, searchConstants, and constantCsv.
  5. Export is observable. onExport(csv) fires before the browser download. The component does not upload anything.

Provenance

Values are parsed from the NIST Fundamental Physical Constants complete listing of CODATA 2022 recommended values. NIST does not endorse this component. The featured and SI-defining subsets are editorial selections over that data; the identifiers are Aperture’s slugs, not NIST identifiers. Verify before publication, and cite the CODATA report rather than this component.

Accessibility

  • The search field has a label, an Escape shortcut, and a live result count. Filter buttons expose their pressed state; the list uses a roving tab index so it is one stop, not 355.
  • Each list item is a button with a complete accessible name: symbol, name, formatted value, and unit. Selection uses aria-pressed.
  • The detail panel is a labeled region with a heading-led definition list. Value and uncertainty are in semantic text, not an image.
  • Copy actions report “Copied” in the button label. The CSV is available even when the clipboard API is unavailable.
  • Layout uses logical properties and container queries. At 320 px the detail panel moves below the list without a page-level horizontal scroll.
  • There are no entrance animations or counting numbers. Reduced-motion users see the same list immediately.

Preview status

The full listing, search, filters, detail panel, copy actions, and CSV are complete and tested. The defaults still need a domain-advisor review: the featured selection, the dimensionless wording, unit typesetting for compound expressions, uncertainty presentation, and whether the truncated exact decimals should be completed from the CODATA report. Treat this instrument as usable, not final. The Spectrum Plot and Periodic Table carry the same preview status.
