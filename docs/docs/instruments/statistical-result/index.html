Statistical Result Block

p < 0.05 is a claim with the uncertainty removed. This block renders a result the way a statistician would insist on: estimate, interval, n, test, effect size, assumptions, and the exact p-value.

Use Copy result for a sentence that can go straight into a draft.

What it checks

  • A p-value never rounds to zero. Values below 0.001 render as p < 0.001. The computed value is not replaced by a bold claim.
  • The interval contains the estimate. If it does not, the block says so instead of drawing an impossible strip. An estimate without an interval is labelled as hiding its uncertainty.
  • The interval and the p-value agree. An interval that includes the null while p < α — or excludes it while p ≥ α — is flagged. Both are common copy-paste failures.
  • n is not optional. A result with zero or missing n is called out. So is a p-value outside [0, 1].
  • Assumptions carry a status. Met, violated, or not checked — each with the test or diagnostic that supports it. "Not checked" is a legitimate, visible state; pretending otherwise is not.
  • Everything copies as a sentence. The copy action produces the estimate, interval, n, test, p, effect size, assumptions, and method in plain text, ready for a manuscript or a lab meeting note.

The interval strip

The small graphic under the estimate is a scale, not a chart. It spans the interval with 12% padding, marks the null value with a dashed rule, and places the estimate on the line. It exists because "the interval excludes zero" is easier to verify than to read. It is hidden from assistive technology; the same fact is in the sentence.

Data contract

  1. Result. estimate, n, test, and p are required. unit, precision, interval, nullValue, alpha, effectSize, correction, tails, assumptions, method, and warning are optional.
  2. Interval. Level, lower, upper, and kind — confidence, credible, or prediction. The kind is displayed verbatim, so a prediction interval is never presented as a confidence interval.
  3. Test. A human-readable name, not an enum. The component does not compute the test; it refuses to display an unnamed one.
  4. Helpers. formatPValue, describeStatisticalResult, resultToText, and resultWarnings are exported and tested against reference values.

Accessibility

  • The estimate, interval, and p-value are text first. The interval strip is decorative and marked aria-hidden.
  • Assumption status uses a glyph plus a word: ✓ met, × violated, ? not checked. Color is the second cue.
  • The copy button reports "Copied" as visible text and does not move focus.
  • Units and intervals wrap at narrow widths; the 320 px layout stacks the hero and the definition list without a horizontal scroll.
  • No animated number counting. A result should not flicker into place.

Status

Ready. It renders a result; it does not compute one. That boundary is deliberate: the statistics belong to the analysis package, and the reporting contract belongs here.
