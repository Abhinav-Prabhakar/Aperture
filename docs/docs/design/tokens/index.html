DesignContract

Design tokens

Components consume semantic tokens only. No raw hex, norgb(), nohsl(). The complete contract is in design.md.

Toggles the high-contrast token override.

Monochrome brand

There is no brand hue. Identity comes from the aperture mark, the type hierarchy, hairlines, and the grid. Color appears only to encode data or status.
