Aperture

A copy-paste UI system for scientific software. Start with an element, compose an instrument, and ship a workbench you own.

Pre-alphaMITReact 19 · Tailwind 4

Phase 1 is well underway.

The element layer, tokens, registry pipeline, all twelve founding instruments, the first life-sciences instrument, and all five workbenches are in place. The rest of the domain pack is next.

The three layers

Elements
Accessible primitives: 56 vendored from coss/ui, plus research additions as they land.
56 readyOpen
Instruments
Research-native components: quantity input, uncertainty, tables, logs, protocols, sequences.
13 builtOpen
Workbenches
Complete screens: workspace shell, data explorer, lab dashboard, run detail, sample registry.
5 readyOpen

Install

The CLI and registry commands are the contract. They are implemented as the registry publishes.

Where to start

  • ButtonVariants, sizes, loading, and icon composition.
  • CardThe panel grammar used across every workbench.
  • Workspace ShellThe frame: navigation, command palette, inspector, and status bar.
  • Data ExplorerThe first complete workbench, with every state.
  • Lab DashboardInstrument health, alerts, samples, and the day’s schedule.
  • Run DetailParameters, QC metrics, artifacts, and provenance for one run.
  • Sample RegistryStorage, aliquots, chain of custody, and linked runs.
  • Design tokensThe exact surfaces, type scale, radius, and density.
